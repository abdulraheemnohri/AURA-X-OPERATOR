# AURA-X NEXUS — RAG / Embedding Truth

## Change

The knowledge-base index no longer stores or searches pseudo-embeddings generated by a local hash function.

A hash vector is not a semantic embedding and must not be presented as one.

## Current pipeline

```text
Document
  ↓
Normalize
  ↓
Chunk
  ↓
Local JSONL index
  ↓
Lexical retrieval (TF/IDF + phrase bonus)
  ↓
Top-K
```

This path is deterministic, offline, and useful without pretending that semantic inference is available.

## Semantic pipeline contract

```text
Document
  ↓
Chunk
  ↓
EmbeddingRuntime
  ↓
Real model embedding
  ↓
Vector index
  ↓
Semantic retrieval
  ↓
Hybrid merge
  ↓
Re-rank
  ↓
RAG context
```

`EmbeddingRuntime` is now an explicit runtime contract. Until a real local embedding backend and model are installed, semantic embedding remains unavailable rather than being falsely reported as READY.

## Compatibility

Legacy JSONL entries containing the old `vector` field remain readable. The field is ignored. Re-indexing writes version 2 entries containing only the canonical chunk identity, source, and text.

## Next implementation

1. Add a real local embedding backend.
2. Add model/runtime capability gating for embeddings.
3. Persist embedding dimensions and model identity.
4. Re-index automatically when the embedding model changes.
5. Add vector similarity retrieval.
6. Merge lexical and semantic scores.
7. Add bounded re-ranking.
8. Feed verified retrieved context into the local LLM.
9. Add tests for unavailable runtime, model changes, corrupt vectors, empty indexes, and deterministic lexical fallback.
